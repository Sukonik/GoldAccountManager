History: from Payout Lab

The packet is not a new idea. It was proven first in Payout Lab, a free, no-sign-up dividend portfolio tracker.

What Payout Lab proved

Payout Lab has no accounts and no server. The site is static, runs on GitHub Pages for $0 and keeps everything in the browser. The user's portfolio is a packet, a .payout file: plain JSON with holdings, settings and saved reports. Open it on any device to continue. It was the first time the "account is a file you own" idea ran for real users.

What carried over

  • Plain JSON, owned by the user, with the same honest limits stated up front: not encrypted, and a device copy is not a backup.
  • Random identity labels and a revision lineage that classifies copies as identical, newer, older or diverged. No silent last-write-wins.
  • Safe parsing: size limits, whitelisted fields, bounded values, nothing executed.
  • The canonical-JSON SHA-256 checksum. The Go port is tested against vectors produced by Payout Lab's JavaScript, so a checksum computed in either language matches.
  • A design system as a small CSS file: Payout Lab's Green Ion theme became the starting point for Blue Bolt UI.

Not ported yet

Payout Lab's snapshot links, QR cards, saved-report receipts and CSV import are not part of Phase 0. Encrypted packets and passkey or password-manager unlock keys are on both projects' roadmaps.
