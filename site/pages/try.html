Try it in your browser

Make a packet, change it, save it as a file, and open it again. This is the whole idea of GoldAccountManager, running on this page.

Nothing leaves this page

There is no server behind this demo and no sign-up. The packet lives in your browser's memory until you download it, and the page makes no network requests with your data.

Things to try

  1. Round trip. Make a packet, download it, then open the file. It should say identical.
  2. History. Edit the data, press Save my edits as a new revision, then open the file you downloaded earlier. It is now older, and the page offers a separate copy instead of overwriting.
  3. Divergence. Download, save a revision, then open the file after making a different revision from the same starting point. Both changed, so it says diverged.
  4. Tampering. Open a downloaded file in a text editor, change the name, save it, and open it here. You get a checksum warning, and the page tells you that is not proof of who edited it.
  5. Isolation. Change the app id above to other-app and open the same file. It is refused.

What this page does not do

  • It does not check attestation signatures. Browsers differ in Ed25519 support, and the server or Go code is the right place to trust a signature. Here an attestation is only checked for shape.
  • The packet is not encrypted. Do not put anything private in this demo.
  • This reader is a second implementation of the format. It is checked against the Go reader on the same shared test cases, see Packets.
