Blue Bolt UI

One small CSS file and one optional script. Plain HTML looks right with no classes, and the same look runs in light and dark.

Use it

<link rel="stylesheet" href="assets/blue-bolt.css">
<script src="assets/blue-bolt.js"></script>   <!-- optional: theme toggle, copy buttons -->

Native elements (button, input, table, details) are styled as they are. Classes with the bb- prefix add variants and layout.

Where the ideas come from

No code was copied. Each project is a reference for one idea, and licenses are recorded in THIRD_PARTY_NOTICES.md.

ReferenceIdea we took
Green Ion (Payout Lab)CSS-variable themes that follow the device, press feedback, a mobile-first layout, one file with no dependencies.
oat (MIT)Semantic HTML first: style real elements, add classes only for variants. Described by its authors as about 10 KB with no dependencies.
Carbon (Apache-2.0)Role-based color tokens (background, layer, text-primary, border-subtle), a spacing scale built on 2, 4 and 8 pixels, and a 2px focus ring that must keep 3:1 contrast.
GoldBrief UI/UXPrefer native controls before a library, document every state (default, hover, focus, disabled, loading, empty, error), and test from 320 to 1920 pixels. More patterns will be borrowed in later updates.

Accessibility, measured

Every text and surface pair was checked against WCAG 2.2 AA with a script (4.5:1 for text, 3:1 for boundaries and focus). Selected ratios:

PairLightDark
Primary text on background16.8316.06
Secondary text on layer7.948.39
Link on background7.538.85
Button text on interactive6.706.85
Input border on layer (needs 3)3.983.40
Focus ring on background (needs 3)6.258.85
  • Controls are at least 44 pixels tall. Focus is a 2px ring on every interactive element.
  • Honors prefers-reduced-motion, forced-colors and print.
  • Works without JavaScript. The script only adds the theme toggle and copy buttons.
Not yet verified

The checks above are numeric. The site has not been tested with a screen reader, on a physical phone, or in Safari and Firefox.
